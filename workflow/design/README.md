# Design notes

One note per feature (`<feature>.md`), each with a status of `exploring | approved | built`, linking
its samples and tasks. The **master design** lives at the repo root
(`Fleet_Control_Monitoring_Platform_Architecture.md`) and is the source of truth; these notes track
how each feature is realized from it.

`samples/` holds UI sample pages and the sample kit (added with the first panel task).
