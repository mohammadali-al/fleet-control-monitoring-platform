# Fleet Panel — Hacker Restyle Samples, Round 2 (T-0034)

Five new standalone visual skins of the exact same Fleet panel slice (sidebar navigation, top bar, `Machines` view with 4 summary tiles and a 6-row mock registry table, plus an interactive `Terminal` session panel), acting on the round-1 review feedback (`review.md`) to push for real aesthetic novelty while preserving layout, controls, and legibility.

- **[sample-1.html](sample-1.html) — Clean P31 Oscilloscope (Refined Phosphor)**: Carries forward round-1 sample-1's green-phosphor legibility while stripping away noisy CRT scanlines and fuzzy text bloom, reframing the UI as a precision lab instrument with faint 64 px graticule divisions, calibration ruler tick marks, L-bracket corner reticles, and stepped LED bargraph meters. Uses **Martian Mono** for display titles, card headers, and stat counters paired with **IBM Plex Mono** for body text, tables, and terminal output. Accent `#2ef28b` (P31 phosphor mint) over `#050a07` background and `#08100b` / `#0d1811` surfaces, with `#173322`–`#28593b` borders.

- **[sample-2.html](sample-2.html) — Daylight Technical Broadsheet (Paper & Ink Hacker)**: Subverts the dark-mode hacker trope with a crisp archival-vellum engineering broadsheet featuring heavy carbon-ink rules, hard 3 px offset stamp shadows with tactile button depression, and a high-contrast dark obsidian hardware scope embedded for the `Terminal` panel. Uses **Space Mono** for headings, nav labels, and stat counters paired with **Red Hat Mono** for dense registry rows, controls, and terminal text. Accent `#d9480f` (international orange) and `#1d4ed8` (blueprint cobalt) over `#f3efe6` paper background and `#fbf9f3` / `#ede8dc` surfaces, with `#181a18` carbon-ink borders.

- **[sample-3.html](sample-3.html) — Tactile Hardware Console (Olivetti / Field Synth)**: Evolves round-1 sample-2's calm retro warmth into a physical industrial console with sculpted PBT-keycap button bevels, sunken LCD-bay stat tiles, rocker-switch filters, and subtle knurled card header trim. Uses **Spline Sans Mono** for headings, labels, and stat readouts paired with **Fira Code** for table data and terminal output. Accent `#ff5a26` (cadmium vermilion) and `#6fcf97` (sage phosphor) with `#eee8dd` bone text over `#161513` matte charcoal background and `#1f1d1a` / `#282521` surfaces.

- **[sample-4.html](sample-4.html) — TUI Framebuffer (Deep Petrol + Acid Chartreuse)**: Rejects rounded web cards and drop shadows in favor of a strict `0 px`-radius text-mode wireframe shell with double-ruled headers, inset inner outlines, inverted-video active selection bars, and bracketed `[ ... ]` text-mode chips and primary actions. Uses **Syne Mono** for display headings and oversized stat counters paired with **Azeret Mono** for tables, inputs, and terminal text. Accent `#c6ff33` (acid chartreuse) and `#4dd4e8` (cyan-sky) with `#ebe6d5` parchment text over `#061519` petrol-teal background and `#0a1e24` / `#0f2a32` surfaces.

- **[sample-5.html](sample-5.html) — Swiss Brutalist Monochrome + Signal Red**: Strips the interface down to stark achromatic black and bone-white typography with radical weight contrast (`300`–`800`), slashed zeros, heavy `2 px` structural rules, and halftone dot-matrix header strips, reserving a single vivid chromatic hue for primary triggers, active cursor, and critical alerts. Uses **JetBrains Mono** across all weights and scales (`font-variant-numeric: slashed-zero tabular-nums`). Accent `#ff2a3c` (signal crimson) over `#09090b` void black background and `#101014` / `#17171c` surfaces, with `#f4f4f0` stark bone ink and `#272730`–`#4a4a58` rules.
