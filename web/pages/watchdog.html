Watchdog

Keeps a machine from hitting maximum resource use and becoming unreachable. It is a load safety net, not a tamper-proof supervisor: everything else is for the human watching this panel.

Thresholds sit above the Load Controller's operating ceiling. A Maneuver deliberately drives CPU and RAM toward its ceiling; the watchdog only acts as a backstop for load that escapes the controller, such as a runaway manual command.

Policy profile

Version-stamped YAML, stored on the main server, pushed over the control channel and applied live without a restart.

Detection
Clears only below this level.
Escalation ladder
  1. 1. Throttle
    Transient CPU quota, optional egress shaping; lifted early on recovery.
  2. 2. Kill offending session
    The session's whole process group is killed in one action. Never per-socket.
  3. 3. Service restart
    Restarts the offending unit.
  4. 4. Machine reboot
    The agent reconnects by itself after boot.
Guards
No actions right after boot.

When the daily caps are used up the host goes alert-only: it keeps measuring and reports here, but takes no further action until an operator resets the counters.

Saving pushes the new version to every host in scope; the last known profile keeps running if the main server is unreachable.
