Backup

A storage-only replica of the main server's archive. It is not a standby control plane. Replication is additive: nothing is ever deleted on the backup server.

Backup reminder. This reminder shows at most once a day.

Add or replace backup server

The password is used once, to install a key; it is not stored unless the key cannot be installed. After adding a server the panel computes the diff and suggests a schedule.

Import from the backup server?

Reads data from the fixed backup path and restores it on this main server.

Use this to rebuild a main server. A local file that differs from the backup is kept and reported, unless you choose to overwrite; nothing is deleted on either side.
